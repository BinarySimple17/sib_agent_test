# Currency Converter

Конвертер валют через командную строку с актуальными курсами Банка России.

Парсит таблицу курсов с сайта [ЦБ РФ](https://www.cbr.ru/currency_base/daily/) и выполняет конвертацию между любыми двумя валютами через кросс-курс в рублях.

## Возможности

- 🔄 Актуальные курсы с сайта ЦБ РФ (без API-ключа)
- 🌐 Кросс-конвертация через рубль между любыми валютами
- 📴 Оффлайн-режим с фиксированными курсами
- 🎯 Точные вычисления через `Decimal` с округлением до 2 знаков
- 📦 Только стандартная библиотека Python — никаких зависимостей

## Установка

Скрипт не требует установки зависимостей. Достаточно Python 3.10+:

```bash
git clone <repo-url>
cd currency-converter
```

## Использование

### Базовый синтаксис

```bash
python currency_converter.py <СУММА> <ИЗ_ВАЛЮТЫ> <В_ВАЛЮТУ>
```

### Примеры

```bash
# 100 долларов в рубли
python currency_converter.py 100 USD RUB
# → 100.0 USD = 9259.63 RUB

# 50 евро в доллары (кросс-курс через рубль)
python currency_converter.py 50 EUR USD
# → 50.0 EUR = 59.59 USD

# 1000 рублей в юани
python currency_converter.py 1000 RUB CNY
# → 1000.0 RUB = 92.50 CNY

# Оффлайн-режим (без запроса к сайту ЦБ)
python currency_converter.py 100 USD RUB --offline
# → 100.0 USD = 7429.63 RUB
```

## Аргументы командной строки

| Аргумент | Тип | Обязательный | Описание |
|----------|-----|-------------|----------|
| `amount` | float | ✅ | Сумма для конвертации |
| `from_currency` | str | ✅ | Исходная валюта (3 буквы, например USD) |
| `to_currency` | str | ✅ | Целевая валюта (3 буквы, например RUB) |
| `--offline` | flag | ❌ | Не запрашивать сайт ЦБ, использовать фиксированные курсы |

## Поддерживаемые валюты

**Онлайн** — все валюты, публикуемые ЦБ РФ на текущий день (40+ валют: USD, EUR, GBP, CNY, JPY, CHF, KZT, TRY, AED, INR и др.).

**Оффлайн (fallback)** — фиксированный набор: USD, EUR, RUB, GBP, CNY, JPY, CHF, CAD, AUD, KZT.

## Как это работает

1. Скрипт загружает страницу `https://www.cbr.ru/currency_base/daily/`
2. Парсит HTML-таблицу с курсами (библиотека `html.parser`)
3. Извлекает буквенный код валюты, номинал и курс в рублях
4. Вычисляет цену 1 единицы валюты: `rate = курс / номинал`
5. Конвертирует через кросс-курс: `результат = сумма × (rate_from / rate_to)`

Если сайт ЦБ недоступен, скрипт автоматически переключается на фиксированные курсы.

## Обработка ошибок

| Ситуация | Поведение |
|----------|----------|
| Неверный код валюты | `❌ Ошибка: Неизвестная валюта: ...` (exit 1) |
| Сайт ЦБ недоступен | Автоматический переход на fallback-курсы |
| Неверная сумма | `❌ Ошибка: ...` (exit 1) |
| Непредвиденная ошибка | `❌ Непредвиденная ошибка: ...` (exit 2) |

## Зависимости

Только стандартная библиотека Python 3.10+:

- `argparse` — парсинг аргументов CLI
- `urllib.request` — HTTP-запрос к cbr.ru
- `html.parser` — парсинг HTML-таблицы
- `decimal` — точные вычисления с деньгами
- `sys` — коды возврата
